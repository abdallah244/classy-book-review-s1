# Classy Book

Welcome to **Classy Book**, a comprehensive modern platform for education and social interaction.

## ?? Overview
Classy Book provides a robust platform for managing courses, users, and social interactions. Built with a scalable architecture, ensuring maximum performance and high availability.

## ?? Technologies
- **Frontend**: Angular 19
- **Backend**: NestJS (Node.js/TypeScript)
- **Database**: MongoDB & Redis
- **Realtime**: WebSockets (Socket.io)

## ?? Project Structure
- `/frontend`: Angular Single Page Application.
- `/backend`: Scalable NestJS REST APIs and WebSocket Gateways.
- `/docs`: Detailed project documentation.
